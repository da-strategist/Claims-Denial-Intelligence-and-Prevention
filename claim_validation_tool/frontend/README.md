# ClaustraRCM frontend

React 19 + Vite + Tailwind CSS v4. See the [project README](../README.md) for setup and the
[project guide](../PROJECT_GUIDE.md) for conventions.

| Script | What it does |
|---|---|
| `npm run dev` | Dev server on http://localhost:5173, proxying `/api` to the backend on port 8000 |
| `npm test` | Vitest + Testing Library, once (`npm run test:watch` to keep watching) |
| `npm run lint` | oxlint |
| `npm run build` | Production build to `dist/` |
